# One-Line Roast: The Gadget You Use Every Day

Entry for the make.fun bounty **u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610**
("One-Line Roast: The Gadget You Use Every Day").

`main.ts` is a self-contained Node program: it writes the entry line to
`/output/entry.txt`, deterministically — the same bytes on every run,
no network, no clock, no randomness.

The line:

> My phone has 256 GB of storage, a chip smarter than the Apollo program, and exactly one job it fails daily: waking me up on the first alarm.
